Real claims, not marketing copy

Three concrete things you can verify yourself, not just take our word for.

A

Source-relative, not one-size-fits-all

Every source on your network gets its own learned baseline. Nothing is scored against a single global "normal."

B

Measured, not promised

Detection rates are measured on public datasets (CSE-CIC-IDS2018, UNSW-NB15) and published, and a detector that has not been measured says so — methods you can look up and evaluate independently, not a black-box model.

C

Isolated, not shared

Each Raingaia Network customer is provisioned their own analysis engine and database. Traffic and findings are never pooled into a shared multi-tenant store.

02

The shared discipline

Four principles behind every verdict Raingaia Network produces.

01
Source-relative baseline
Every source gets its own learned baseline instead of one global "normal." A warmup period establishes what normal looks like specifically for that source before anything is scored against it.
02
Multi-channel evidence fusion
Independent signal channels are tracked and decayed separately, then fused into one composite assessment — cross-checking multiple views of the same event instead of trusting a single signal alone.
03
Deterministic, probabilistic decisions
Behavioral verdicts come from a source-relative probability distribution over possible states — and the same input always produces the same output, so any alert can be replayed and checked.
04
Tamper-evident audit trail
Every incident's evidence is sealed with a keyed integrity check, and every response command is recorded in a hash-chained audit trail on the customer's own machine — a retroactively altered record no longer verifies.
